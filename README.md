# Cuneiform Search Tool

This is a program to search through cuneiform text for syntactic and stylometric purposes.

## Note

The code in this project has been quickly put together for others to use as soon as possible and thus has a lot of quick hacks and workarounds in order to obtain the data as quickly as possible.
Refactors and better practices are planned but not a priority until there is no longer a strict time constraint on when the data needs to be available.
